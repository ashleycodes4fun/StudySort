# StudySort

Built from my own experience with ADHD, StudySort is a study planner designed to reduce overwhelm, organize assignments, and help students focus on what to do next.

## Live Demo

[Open StudySort](https://studysort-ashley.streamlit.app/)

## Features

- Add and organize assignments
- Prioritize tasks by due date, difficulty, and energy level
- Break large assignments into smaller steps
- See a focused "Start Here" recommendation
- Track completed tasks and overall progress
- Use a customizable focus timer with a ringtone
- Use a Brain Dump section for unorganized thoughts

## Built With

- Python
- Streamlit
- pandas

## Why I Built It

Traditional planners did not always help me organize my thoughts or decide what to work on first. I built StudySort to create a simpler way to break down assignments, prioritize tasks, and focus on one next step at a time.
